# Code of Conduct

This project follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, be constructive, assume good faith, and keep the
space welcoming for everyone regardless of background or experience level.

Report unacceptable behavior through the repository's private security
reporting channel; maintainers will handle reports confidentially.
